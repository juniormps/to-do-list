# AGENTS.md - Regras para o assistente de IA

## Diretrizes Gerais

- Siga os padrões de código estabelecidos no projeto
- Escreva testes para novas funcionalidades
- Documente funções complexas

## Preferências de Código

- Use TypeScript para novos componentes
- Prefira composição sobre herança
- Mantenha funções pequenas e com responsabilidade única

## Fluxo de Trabalho

- Antes de criar novos arquivos, verifique se já não existem similares
- Para tarefas complexas, planeje antes de codificar
- Utilize o modo agente para tarefas que exigem múltiplos arquivos
